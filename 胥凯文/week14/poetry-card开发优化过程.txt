项目名称：poetry-card（诗词卡片生成器）
项目类型：豆包 Agent Skill
输出格式：中国风 HTML 静态页面
开发时间：2026-08-05
开发方式：用户逐步提出需求，迭代修改完善

================================================================================
一、项目概述
================================================================================

当用户说"给我做张xxx诗人的诗词卡"、"给我xxx诗人的诗词"等类似表达时触发，
为指定诗人生成包含以下内容的精美中国风 HTML 静态页面：
  - 诗人简介（文学地位、风格特点）
  - 生平经历（做官、罢官、贬谪、战乱、游历等）
  - 3首代表作（含全诗、逐句白话译文、赏析）
  - 3句经典诗句（含原文、出处、详细解释）
  - 风格标签

页面采用中国传统色配色，响应式设计，支持打印。

【第1步：初始创建】
用户要求：帮我制作一个项目级的 skills，这个 skills 是可以帮助我学习诗词的卡片，一个诗人，出一个 html 静态页面，上面有诗人的诗词以及诗词注解，当我说 “给我做张 xxx 诗人的诗词卡”，“给我 xxx 诗人的诗词” 类似的时候触发，输出的 html 放在当前目录下，原始数据存在 skill 下的文件夹内

【第8步：从 token 消耗、执行效率角度优化 Skill】
用户要求：继续优化 skill，从 token 消耗、执行效率等角度优化，
          并输出优化前后的对比。

优化成果：

  | 文件             | 优化前  | 优化后  | 减少   | 降幅 |
  |------------------|---------|---------|--------|------|
  | SKILL.md         | 3,984 B | 2,395 B | 1,589B | 40%  |
  | template.html    | 8,703 B | 4,550 B | 4,153B | 48%  |
  | generate.py      | 5,111 B | 3,175 B | 1,936B | 38%  |
  | 数据文件         | 17,349B | 17,349B | 0      | 0%（内容不缩水） |
  | Skill 总计       | 35,147B | 27,469B | 7,678B | 22%  |
  | 生成的 HTML（李白）| ~17.5KB | 14.7KB  | ~2.8KB | 16%  |

具体优化措施：

  generate.py：
    - 去掉未使用的 os 模块导入
    - 8次独立 str.replace() → 字典批量替换，1次循环完成，减少字符串复制
    - 列表 append + join → 生成器表达式 + join，减少中间列表内存
    - 合并重复条件逻辑，用三元表达式内联
    - 去掉 f-string 中大量用于缩进的空格和换行（不影响浏览器渲染）
    - 错误提示更紧凑

  template.html：
    - CSS 从"每行一个属性"压缩为"每个选择器一行"，保持可读性
    - 合并 .poem-annotation h4, .poem-appreciation h4 等共同选择器
    - 去掉 CSS 中多余的空行
    - HTML 结构去掉无意义的嵌套缩进
    - 媒体查询紧凑排列
    - 视觉效果零变化（已在浏览器验证）

  SKILL.md：
    - 去掉未使用的 portrait_hint 字段说明（脚本和数据都不用）
    - 精简触发示例和工作流程描述
    - 关键信息（数据格式、质量要求）完整保留

执行效率提升：
  - 模板文件更小，磁盘 IO 更快
  - 字符串替换次数从 8 次减为 1 次循环
  - 生成的 HTML 文件更小，加载更快
  - 按 token 估算，Skill 加载时减少约 2500-3000 tokens

【第11步：经典诗句不能和代表作品重复】
用户要求：经典诗句中的句子不能和代表作品中的重复。

检查发现问题：
  - 李白："天生我材必有用"出自《将进酒》，而将进酒在3首诗中 ❌
  - 杜甫："烽火连三月"出自《春望》，"无边落木萧萧下"出自《登高》，两首都在 ❌
  - 白居易：三句全部出自那3首诗 ❌

修改内容：

  李白（代表作：将进酒、静夜思、蜀道难）：
    - 替换：天生我材必有用（将进酒）→ 飞流直下三千尺，疑是银河落九天（望庐山瀑布）
    - 保留：长风破浪会有时（行路难，不在3首中）
    - 保留：举杯邀明月（月下独酌，不在3首中）

  杜甫（代表作：春望、登高、茅屋为秋风所破歌）：
    - 保留：会当凌绝顶（望岳，不在3首中）
    - 替换：烽火连三月（春望）→ 随风潜入夜，润物细无声（春夜喜雨）
    - 替换：无边落木萧萧下（登高）→ 露从今夜白，月是故乡明（月夜忆舍弟）

  白居易（代表作：赋得古原草送别、琵琶行、问刘十九）：
    - 替换：野火烧不尽（赋得古原草送别）→ 在天愿作比翼鸟，在地愿为连理枝（长恨歌）
    - 替换：同是天涯沦落人（琵琶行）→ 可怜身上衣正单，心忧炭贱愿天寒（卖炭翁）
    - 替换：晚来天欲雪（问刘十九）→ 人间四月芳菲尽，山寺桃花始盛开（大林寺桃花）

  SKILL.md 质量要求新增一条：
    "经典诗句不得选自本卡片收录的3首代表作，应选自该诗人其他名篇，让读者接触更多作品"

修改原因：避免内容重复，让读者在有限篇幅内接触到诗人更多的作品。

{
  "name": "诗人名",
  "dynasty": "朝代",
  "title": "称号",
  "bio": "第一段简介，200-500字，概述文学地位、风格特点、主要成就",
  "career": "第二段生平，200-400字，重点写做官、罢官、贬谪、战乱、游历",

    // 共3句，且不得来自下面的3首诗
  ],
  "poems": [
    {
      "title": "诗名",
      "content": "全诗原文，换行用\n",
      "translation": "逐句白话译文",
      "appreciation": "赏析，100-300字"
    }
    // 共3首
  ]
}

================================================================================
五、最终质量要求
================================================================================

1. 每位诗人收录3首代表作
2. 每位诗人收录3句经典诗句，每句包含：原文、出处、详细解释
3. 【重要】经典诗句不得选自本卡片收录的3首代表作，应选自其他名篇
4. 诗人简介分两段：第一段概述文学地位与风格，第二段详述生平经历
5. 译文为逐句白话翻译，不是词语注释
6. 赏析要有深度，帮助理解诗词意境
7. 中国风设计，三板块用浅赭/天青/秋香三色，配色典雅
8. 响应式设计，适配手机，支持打印

================================================================================
六、生成命令
================================================================================

python <skill_path>/scripts/generate.py <诗人名> [输出目录]

示例：
python generate.py 李白
python generate.py 白居易 ./output

输出文件名：诗词卡-诗人名.html
