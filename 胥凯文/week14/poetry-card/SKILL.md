# 诗词卡片生成器

为古代诗人生成中国风诗词学习卡片HTML页面。

## 触发场景

- "给我做张李白的诗词卡"
- "给我杜甫的诗词"
- "苏轼诗词卡片"
- "来一张王维的诗词学习卡"

## 工作流程

1. **确定诗人**：从用户请求提取诗人姓名
2. **检查数据**：查看 `data/诗人名.json` 是否存在
   - 已存在 → 直接使用
   - 不存在 → 搜索收集信息，按下方格式创建JSON存入 `data/`
3. **生成HTML**：运行脚本
   ```bash
   python <skill_path>/scripts/generate.py <诗人名> [输出目录]
   ```
   输出文件：`诗词卡-诗人名.html`，默认输出到当前目录
4. **交付**：将生成的HTML文件路径告知用户

## 数据格式

`data/诗人名.json` 结构：

```json
{
  "name": "李白",
  "dynasty": "唐代",
  "title": "诗仙",
  "bio": "简介，200-500字，概述文学地位、风格特点、主要成就",
  "career": "生平经历，200-400字，重点写做官、罢官、贬谪、战乱、游历等",
  "style_tags": ["浪漫主义", "豪放", "想象奇特"],
  "classic_lines": [
    {
      "text": "天生我材必有用，千金散尽还复来",
      "source": "《将进酒》",
      "explanation": "详细解释，50-150字"
    }
  ],
  "poems": [
    {
      "title": "将进酒",
      "content": "全诗原文，换行用\n",
      "translation": "逐句白话译文",
      "appreciation": "赏析，100-300字"
    }
  ]
}
```

## 质量要求

- 3首代表作，3句经典诗句（含原文、出处、解释）
- **经典诗句不得选自本卡片收录的3首代表作**，应选自该诗人其他名篇，让读者接触更多作品
- 简介分两段：文学概述 + 生平经历
- 译文为逐句白话翻译，不是词语注释
- 赏析有深度，帮助理解意境
- 中国风设计，配色典雅，适合阅读和打印
